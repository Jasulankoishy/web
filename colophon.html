How the Site Works

Eight HTML pages

This project has eight HTML pages. The same menu is at the top of every page, so you can move between them. Each page has its own title and text. The site uses only HTML.

The browser reads the HTML tags and shows the page. Headings divide the text into parts. Tables put information in rows and columns. To start, open index.html.

Press Tab to move between links and fields. If you leave a required field empty, you may see Please fill out this field. The message depends on the language of your browser.

How the forms work

The three forms use GET and open the same page again. Personal fields have no name attribute, so those values stay out of the page address. Only the order type goes into the address. Nothing is booked or sent to SF.
